## 📌 Features

- **Sleek & Modern UI/UX**: Tech dark aesthetic with vibrant glowing gradients, glassmorphic cards, and smooth CSS animations.
- **Dark / Light Mode**: Integrated theme switcher with persistent settings saved in `localStorage`.
- **Honest Skill Categorization**: Clear distinction between working practical skills and active learning roadmap.
- **Project Showcases**: Direct GitHub buttons and detailed summaries for hackathons and internship projects.
- **1-Click Copy & Mobile Contact**: One-tap phone dialing (`tel:`) and email copying with toast notification feedback.
- **Fully Responsive**: Optimized for desktop, tablet, and mobile viewing with a slide-out hamburger navigation menu.

## 🛠️ Tech Stack & Tools

## 🚀 Local Development

To run the portfolio locally on your machine:

1. Clone this repository:
   ```bash
   git clone https://github.com/Karanthakur7/portfolio.git
   ```
2. Navigate into the project folder:
   ```bash
   cd portfolio
   ```
3. Start a local HTTP server:
   ```bash
   python -m http.server 8000
   ```
4. Open your browser and go to:
   ```
   http://localhost:8000/
   ```
